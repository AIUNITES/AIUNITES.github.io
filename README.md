# AIUNITES.github.io

Root GitHub Pages site for the AIUNITES network. Serves at `https://aiunites.github.io/`.

## Purpose
- Google Search Console verification (root-level)
- Sitemap index pointing to all AIUNITES sub-site sitemaps
- Redirects to main hub at `/aiunites-site/`

## Files
| File | Purpose |
|------|---------|
| `index.html` | Redirect to aiunites-site + GA tracking |
| `googled9d9a485d256e459.html` | Google Search Console verification |
| `sitemap.xml` | Sitemap index (links to all 17 sub-site sitemaps) |
| `robots.txt` | Points crawlers to sitemap index |

## Adding New Sites
When a new AIUNITES site is created, add its sitemap to `sitemap.xml`.
